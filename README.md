# EmbyProxy-CF-FAKE

Cloudflare Workers 版 Emby 反向代理 + 伪装观看（保活）一体脚本。

- 反向代理访问你的 Emby 服务器（隐藏真实地址，面板化管理多节点）
- 下载时自动执行伪装观看：模拟真实播放器心跳（每 10s 上报一次进度），60~300s 随机停止并删除播放记录
- 自动/手动保活：隔 N 天自动模拟观看一次，保持账号活跃
- 绑定 Durable Objects 后可执行完整 90~300s 真实心跳模拟播放，不受 CF 单请求 30s 墙钟限制

当前版本：**3.5.0（beta）**（更新日志见 [changelog.json](changelog.json)）

---

## 一、快速部署

1. 打开 Cloudflare Dashboard → **Workers & Pages** → **创建 Worker** → 名称随意（如 `embyfandai`）
2. 打开 Worker → **编辑代码** → 清空 → 粘贴 `worker.js` 全部内容 → **保存并部署**
3. 部署完成后访问你的 Worker 域名（`https://<worker>.workers.dev` 或自定义域名），用管理密码进入面板

> 混淆提示：如果自行混淆后再部署，请务必保留 `export class KeepAliveDO`、绑定变量名 `KEEPALIVE_DO`、以及 `export default` 结构，否则 Durable Objects 将无法绑定。

## 二、绑定配置

在 Worker 的 **设置 → 绑定** 中配置：

| 类型 | 变量名 | 说明 |
| --- | --- | --- |
| 文本变量 | `ADMIN_TOKEN` | 面板管理密码（必需） |
| D1 数据库 | `DB` | 面板/节点/保活数据存储（必需） |
| D1 数据库 | `DB2` | 辅助数据库（如需） |
| Durable Objects | `KEEPALIVE_DO` | 保活长任务（可选，强烈建议） |
| 文本变量 | `TG_BOT_TOKEN` / `TG_CHAT_ID` | 保活结果推送通知（可选） |

## 三、Durable Objects 绑定教程（保活长任务）

绑定后，手动/自动保活的模拟播放升级为 **DO 长任务**：

- 播放时长 90~300 秒随机
- 每 10s 上报一次真实进度心跳
- 起点为影片片长的 2%~10% 随机位置
- 结束后自动 Stopped，并延迟 1.5s 删除播放记录（PlayCount / 继续观看进度重置）
- 全程面板实时显示进度，不受 CF 单请求 30s 墙钟限制
- **未绑定则自动降级**为请求内 20~25s 快速模拟版，功能不中断

### 绑定步骤

1. **先部署代码**：确保已部署的版本包含 `export class KeepAliveDO`（DO 绑定下拉只识别已部署代码中具名导出的类，编辑器草稿无效）
2. **设置 → 绑定 → 添加绑定 → Durable Objects**
3. 填写：
   - **变量名称**：`KEEPALIVE_DO`（代码中写死读取此变量名）
   - **耐用对象（类名）**：`KeepAliveDO`（从下拉选择，注意要**点选匹配项**确认，不能只输入不选中）
4. **生产 / 预览两个环境都要绑定**
5. 保存 → 重新部署

### 常见问题

- **下拉「未找到 耐用对象」**：① 类没有通过 `export class KeepAliveDO` 具名导出（放在 `export default {}` 对象里的写法 Cloudflare 不识别）；② 部署的不是最新版本；③ 需要刷新页面后再进绑定页
- **变量名填错**：绑定变量名必须是 `KEEPALIVE_DO`，自定义其他名字代码读不到，会静默降级为快速版
- **绑定后仍走快速版**：确认生产环境已绑定、且保活请求里有 PlaySessionId

## 四、保活功能

### 自动保活

- 每个节点在面板中单独开启，并设置自己的间隔（`ka_days`），各节点独立计时，互不影响
- **不依赖 Cron**：有人访问面板/代理时自动检查到期节点并执行（1 小时节流）
- 可选配 Cron 触发器（如每天 `*/5 * * * *`）作为无人访问时的兜底
- 绑定 DO 后，自动保活同样执行完整 90~300s 真实心跳模拟

### 手动保活

面板节点卡片点「保活」立即执行：登录 → 拉流 40MB → 模拟播放 → 清播放记录。

### 下载伪装观看

下载文件时伴随执行，模拟真实播放器行为：

- 固定每 10s 上报一次心跳，进度每次 +10s
- 60~300s 随机一个时间点主动停止
- 停止后延迟 1.5s 重置该条目播放记录（不清除整个观看历史）
- 三端（Loon 插件 / VPS / CF Worker）行为一致
