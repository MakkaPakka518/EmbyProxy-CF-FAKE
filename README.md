Cloudflare Workers 版 Emby 反向代理 + 伪装观看（保活）一体脚本。

- 反向代理访问你的 Emby 服务器（隐藏真实地址，面板化管理多节点）
- 下载时自动执行伪装观看：模拟真实播放器心跳（每 10s 上报一次进度），60~300s 随机停止并删除播放记录
- 自动/手动保活：隔 N 天自动模拟观看一次，保持账号活跃
- **IP 访问控制**：全局白/黑名单、IP/CIDR 网段、国家码整体封锁，被拦可 302 跳转或显示禁用页；`/entry` 逃生入口 + 最高白名单兜底
- 绑定 Durable Objects 后可执行完整 90~300s 真实心跳模拟播放，不受 CF 单请求 30s 墙钟限制
- **测速页预设优选源 30 源**：分组下拉（云枢全域与三网专线、104/162/172 大段家族、198&108 专线、IPv6 霄汉星轨 12 源、第三方备用），来源详情条显示名字/标识/完整 API 地址，点击一键复制
- **综合混合源四源并发**：并发聚合 uouin + cf-speed-dns + 164746 + wetest，提取结果提示显示来源名

## 一、快速部署

1. 打开 Cloudflare Dashboard → **Workers & Pages** → **创建 Worker** → 名称随意（如 `embyfandai`）
2. 打开 Worker → **编辑代码** → 清空 → 粘贴 `worker.js` 全部内容 → **保存并部署**
3. 部署完成后访问你的 Worker 域名（`https://<worker>.workers.dev` 或自定义域名），用管理密码进入面板

> 混淆提示：如果自行混淆后再部署，请务必保留 `export class KeepAliveDO`、绑定变量名 `KEEPALIVE_DO`、以及 `export default` 结构，否则 Durable Objects 将无法绑定。

## 二、绑定配置

在 Worker 的 **设置 → 绑定** 中配置：

| 类型 | 变量名 | 说明 |
| --- | --- | --- |
| 文本变量 | `ADMIN_TOKEN` | 面板管理密码（必需） |
| D1 数据库 | `DB` | 面板/节点/保活数据存储（必需） |
| D1 数据库 | `DB2` | 辅助数据库（如需） |
| Durable Objects | `KEEPALIVE_DO` | 保活长任务（可选，强烈建议） |
| 文本变量 | `TG_BOT_TOKEN` / `TG_CHAT_ID` | 保活结果推送通知（可选） |

## 三、Durable Objects 绑定教程（保活长任务）

绑定后，手动/自动保活的模拟播放升级为 **DO 长任务**：

- 播放时长 90~300 秒随机
- 每 10s 上报一次真实进度心跳
- 起点为影片片长的 2%~10% 随机位置
- 结束后自动 Stopped，并延迟 1.5s 删除播放记录（PlayCount / 继续观看进度重置）
- 全程面板实时显示进度，不受 CF 单请求 30s 墙钟限制
- **未绑定则自动降级**为请求内 20~25s 快速模拟版，功能不中断

### 绑定步骤

1. **先部署代码**：确保已部署的版本包含 `export class KeepAliveDO`（DO 绑定下拉只识别已部署代码中具名导出的类，编辑器草稿无效）
2. **设置 → 绑定 → 添加绑定 → Durable Objects**
3. 填写：
   - **变量名称**：`KEEPALIVE_DO`（代码中写死读取此变量名）
   - **耐用对象（类名）**：`KeepAliveDO`（从下拉选择，注意要**点选匹配项**确认，不能只输入不选中）
4. **生产 / 预览两个环境都要绑定**
5. 保存 → 重新部署

### 常见问题

- **下拉「未找到 耐用对象」**：① 类没有通过 `export class KeepAliveDO` 具名导出（放在 `export default {}` 对象里的写法 Cloudflare 不识别）；② 部署的不是最新版本；③ 需要刷新页面后再进绑定页
- **变量名填错**：绑定变量名必须是 `KEEPALIVE_DO`，自定义其他名字代码读不到，会静默降级为快速版
- **绑定后仍走快速版**：确认生产环境已绑定、且保活请求里有 PlaySessionId

## 四、保活功能

### 自动保活

- 每个节点在面板中单独开启，并设置自己的间隔（`ka_days`），各节点独立计时，互不影响
- **不依赖 Cron**：有人访问面板/代理时自动检查到期节点并执行（1 小时节流）
- 可选配 Cron 触发器（如每天 `*/5 * * * *`）作为无人访问时的兜底
- 绑定 DO 后，自动保活同样执行完整 90~300s 真实心跳模拟

### 手动保活

面板节点卡片点「保活」立即执行：登录 → 拉流 40MB → 模拟播放 → 清播放记录。

### 保活全局 UA/ID（保活专用）

账户设置 → **保活全局 UA/ID** 卡片：可一键选用现有模板（SenPlayer / EplayerX / Forward / Rex / Hills / Yamby）、自定义 Client / Device / Version / UA / DeviceId 或随机生成。

- 保活身份优先级：**节点伪装参数 → 保活全局设置 → 内置固定默认**
- **未配置伪装的节点统一用同一套身份**（设备 ID 固定，不再每次随机）——Emby 一般限制设备登录数，随机 ID 会让每次保活新增一个设备、最终刷爆设备数
- 节点已配置伪装参数时仍用节点自身参数

### 下载伪装观看

下载文件时伴随执行，模拟真实播放器行为：

- 固定每 10s 上报一次心跳，进度每次 +10s
- 60~300s 随机一个时间点主动停止
- 停止后延迟 1.5s 重置该条目播放记录（不清除整个观看历史）
- 三端（Loon 插件 / VPS / CF Worker）行为一致

**下载伴随观看身份**：节点设置了伪装参数 → 完整跟随伪装模板（Client / Device / Version / DeviceId / UA 一起换）；未设置 → **透传真实播放器的 UA 和 DeviceId**（认证头原样不替换，上游看到用户自己的设备在看，最自然）

## 五、IP 访问控制（白名单 / 黑名单 / 国家封锁）

设置页 → **IP 访问控制** 卡片（管理员可见）：

- **模式**：关闭 / 白名单（仅命中放行）/ 黑名单（命中跳转）
- **IP 列表**：每行一个 IP 或 CIDR 网段（如 `1.2.3.4`、`5.6.7.0/24`），支持 IPv4/IPv6
- **国家列表**：每行一个 ISO 两位国家码（如 `US`、`RU`、`CN`），支持按国家整体封锁
- **跳转网址**：被拦截时 302 跳转到该地址；不填则显示「你的 IP 已被禁用」页面
- **拦截范围**：面板页面与所有节点链接统一生效（配置前注意别把自己锁外面）

### 原理

1. **统一拦截点**：除系统保留后缀外，所有请求（面板 + 节点链接）在认证/反代前先过 IP 检查。保留后缀 `entry` / `api` / `catch` / `speedtest` / `__client_rtt__` / `favicon.ico` **永不拦截**（`/entry` 是逃生通道，`/api/*` 是面板接口，`/catch` 是反代 Token 门禁页）。
2. **命中判定**：`IP 命中` 或 `国家命中` 即算命中（`ipMatchAny` 支持 IP/CIDR，国家码取 `CF-IPCountry`）。
3. **模式语义**：白名单 = **未命中**拦截（仅名单内可进）；黑名单 = **命中**拦截（名单内被禁）。
4. **拦截动作**：设置过跳转网址 → 302 跳转；未设置 → 直接返回「你的 IP 已被禁用」静态页（显示当前 IP 与所属国家）。
5. **最高白名单（trusted）**：存 D1，命中即放行、**黑/白名单模式均例外**，是管理员的最后兜底。
6. **`/entry` 逃生入口**：只认 `ADMIN_TOKEN` 环境变量密码（**不受反代 Token 模式影响**，Token 模式关着也能登录）；登录成功后当前 IP **自动加入最高白名单**，并在面板/节点全程放行。
7. **无 cookie 逃生**：与普通版一致，面板登录（admin_token cookie）**不**构成 IP 逃生——不在名单内的请求一律拦截，只能通过 `/entry` 登录恢复。最高白名单可在设置页与 `/entry` 就地增删（共享节点的他人 IP 可随时移除）。
